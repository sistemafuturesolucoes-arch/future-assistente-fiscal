# Referência da extensão criada no Lovable

Envie nesta pasta os arquivos-fonte exportados da extensão Lovable para análise e comparação com o Future Assistente Fiscal.

Inclua, se existirem:
- manifest.json
- arquivos JavaScript/TypeScript
- HTML e CSS
- componentes e páginas
- package.json e arquivos de configuração
- imagens e demais assets necessários

Não envie arquivos .env, chaves de API, tokens, senhas, certificados ou dados reais de clientes.

Esta pasta está em uma branch separada e não altera a branch main.
