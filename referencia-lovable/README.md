# Extensão de referência criada no Lovable

Esta pasta é exclusiva para receber a extensão de referência do Lovable. Não misture os arquivos com a extensão Future Assistente Fiscal.

## O que enviar

Envie, preferencialmente, o projeto-fonte completo exportado do Lovable, incluindo:

- `manifest.json` (se já for uma extensão Chrome)
- arquivos JavaScript/TypeScript
- HTML e CSS
- `package.json` e arquivos de configuração
- componentes e imagens usados pela interface
- instruções de execução, se existirem

Se a extensão depender de um backend, inclua apenas o código de integração e um exemplo de configuração sem segredos.

## Segurança antes de enviar

**Não envie** chaves privadas, tokens, senhas, cookies, credenciais, arquivos `.env` reais, dados de clientes ou certificados digitais. Substitua valores secretos por placeholders como `SUA_CHAVE_AQUI`.

## Como enviar

No GitHub, abra esta pasta na branch `reference/lovable-extension-upload`, clique em **Add file → Upload files**, arraste os arquivos e confirme em **Commit changes**. Mantenha os diretórios do projeto.

Depois de enviar, avise nesta conversa. Vou comparar a arquitetura, os seletores, a detecção de menus, os eventos e o comportamento visual com a Future Assistente Fiscal.
